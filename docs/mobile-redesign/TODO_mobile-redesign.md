## 需要你做的真机验收（部署后）

1. **首屏**：打开 APP → 直接是输入界面（无"智能生图"大标题），底部有参数摘要条和生成按钮；
2. **生成流程**：输入描述 → 点生成 → 界面自动上滑进入结果页（进度条在顶部）→ 出图后 2 列网格；
3. **全屏看图**：点任意图 → 全屏；左右滑动切换、下滑关闭；右上「保存」（APP 内）；
4. **返回键**：预览中按 → 关预览；结果页按 → 回输入页（输入内容还在）；再按 → 退出应用；
5. **参数面板**：点底部参数条 → 面板上滑出现（模型/比例/清晰度/数量/对比）；下拉或点关闭收起；
6. **历史**：顶栏时钟图标 → 底部面板 → 点一条记录 → 自动进结果页并显示那组图；
7. **软键盘**：点输入框 → 键盘弹出时生成按钮应被顶到键盘上方（若被键盘遮挡请截图反馈）；
8. **桌面端**：PC 浏览器打开应和以前完全一样。
