# CONSENSUS: mobile-redesign

## 需求描述

安卓端（手机 WebView/PWA/手机浏览器）首页按移动端信息架构重组：输入态与结果态分离，接近原生 App 体验。PC 端（≥640px）保持不变。

## 验收标准

1. <640px 首屏即输入态：无品牌大标题、提示词输入区占主位、底部固定"参数摘要 + 生成"操作区（safe-area 内）。
2. 点生成自动进入结果态（推拉动画）；任务进度置顶；结果 2 列网格；返回键/‹ 退回输入态且输入内容保留。
3. 参数（模型/参考图档位/比例/清晰度/数量/对比）收进底部参数面板；历史收进底部 Sheet，回填后自动进结果态。
4. 点图进全屏预览：左右滑切换、下滑关闭、可见切换按钮；保存/下载按环境（APP=保存到相册，浏览器=下载）。
5. 安卓返回键四层接管：预览 → 面板 → 结果态 → 退出应用；监听器单次注册。
6. ≥640px 桌面结构与行为零变化（回归测试证明）。
7. 门禁：tsc/lint/build；测试：APP mock 18 项 + 浏览器双视口 7 项全过。

## 技术方案（已批准）

专注式两态推拉（否掉底部 Tab 方案）。组件见 FINAL。视觉沿用既有设计令牌；不自绘新视觉语言。ui-ux-pro-max 规则落地：底部固定区 safe-area、触控目标、单一主 CTA、渐进披露（参数面板）、手势替代控件（预览切换按钮）、prefers-reduced-motion 沿用全局降级。

## 约束

- 不引入新依赖（BottomSheet 自绘）；SettingsDialog 保持原样；不改服务端。
- 桌面渲染路径与组件不被替换（新结构仅 <640px 分支）。
